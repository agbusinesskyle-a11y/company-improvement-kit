# External tools and distribution

The MIT license covers authored content shipped here. This preview contains no
vendored runtime, third-party source, model weights, CLI sessions or credentials.

The target uses separately obtained Slack, Grok, GPT-6 access, Spec Kit, Linear,
Ringer, GitHub and Railway tools. Each installer needs its own permitted access
under the tools' terms. Private tool modifications and maintainer subscriptions
are not part of this release. No external provider endorses the project.

Before bundling runtime or another tool, record the exact upstream source, version,
license, required notices and installation method. Private integration versions in
compatibility.json are observations, not a distributable dependency lock or a claim
that every external tool is redistributable.
