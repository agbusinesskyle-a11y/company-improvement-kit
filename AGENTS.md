# Maintaining the reusable skill

Read skills/company-improvements/SKILL.md and docs/status.md before operating or
describing this workflow. Update the skill as implementation progresses. Follow
skills/company-improvements/references/approval-checkpoints.md before every owner
approval request and after its decision. Publish/verify the public snapshot and
save its commit beside the private package. Filled checkpoint records stay private.

Export only explicitly reviewed generic files. Keep private Git history, company
profiles, provider identities, plans, approval evidence, credentials and logs out.
Do not claim runtime enforcement or installability from documentation alone.
Workers propose assigned changes; the maintainer reviews and publishes them.
